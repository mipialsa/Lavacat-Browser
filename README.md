# Lavacat Browser

Lavacat Browser es un navegador para Windows basado en Thorium Browser, diseñado para ofrecer una experiencia rápida, privada y personalizable desde el primer inicio.

Actualmente, **el instalador está disponible únicamente en español**.

## Características

* Basado en Thorium Browser.
* Instalador disponible en español.
* uBlock Origin preinstalado.
* Privacy Badger preinstalado.
* Violentmonkey preinstalado.
* Bypass All Short Links preinstalado.
* Compatible con extensiones de Chromium.
* Configuración inicial orientada a privacidad y personalización.

## Idioma

Por el momento, Lavacat Browser solo dispone de un instalador en **español**.

En futuras versiones podrían añadirse instaladores en otros idiomas.

## Extensiones incluidas

| Extensión                  | Descripción                                                 |
| -------------------------- | ----------------------------------------------------------- |
| **uBlock Origin**          | Bloqueo de publicidad, rastreadores y contenido no deseado. |
| **Privacy Badger**         | Protección frente a rastreadores de terceros.               |
| **Violentmonkey**          | Gestión y ejecución de userscripts.                         |
| **Bypass All Short Links** | Automatización del acceso a determinados enlaces acortados. |

## Compatibilidad

Actualmente Lavacat Browser está destinado a:

* Windows 10
* Windows 11
* Windows x64

## Instalación

Descarga el instalador desde la sección [Releases](../../releases) y ejecútalo.

> El instalador disponible actualmente está únicamente en español.

## Privacidad

Lavacat Browser incluye herramientas destinadas a mejorar la privacidad y reducir el seguimiento en Internet.

Sin embargo, ninguna configuración garantiza privacidad absoluta. La protección depende también de la configuración del usuario, los sitios visitados, los permisos concedidos y los servicios de terceros utilizados.

## Basado en Thorium

Lavacat Browser utiliza Thorium Browser como proyecto base.

Las modificaciones específicas de Lavacat forman parte de este proyecto, mientras que Thorium, Chromium y las extensiones de terceros mantienen sus respectivas licencias.

## Licencias y terceros

Lavacat Browser utiliza software desarrollado por terceros, incluyendo:

Cada componente puede estar sujeto a una licencia diferente. Consulta las licencias correspondientes antes de redistribuir o modificar el navegador.
